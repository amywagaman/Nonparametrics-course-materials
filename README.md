# Nonparametrics-course-materials
Course materials for nonparametric statistics - developed by Brad Hartlaub (Kenyon College) and Amy Wagaman (Amherst College)

Copyright - CC-BY-NC-SA-4.0

The materials in this repository will be discussed as part of a contributed paper session at JSM 2026 in Boston.

The repo was created to support instructors wishing to teach a course in nonparametric statistics. By sharing these resources we've developed for our classes, we hope to reduce barriers instructors may face when teaching the course.

The files provided are arranged by topic, roughly corresponding to certain sections/chapters of the Hollander, Wolfe, and Chicken Third Edition Nonparametric Statistical Methods text (HWC). However, materials may be used without the text. References to HWC are provided when applicable for additional information/reference. 

Within each topic folder, you will find an examples file (or two, depending on the topic), and a lab file with a provided solution, all in .Rmd and rendered pdf format. .Qmd formats for the files may be added in the future when prepared.
